3.5 估计处理效应的元学习器

关于中文版

前几章的方法为整个群体估计一个数字：平均处理效应（ATE），也就是一项处理（treatment）对它触及的所有人的平均影响。但在营销中，平均值可能会误导人。例如，一张优惠券平均可能让购买增加 5%，但这个数字掩盖了真实的故事。有些客户的提升可能高达 20%，另一些客户则毫无反应，甚至出现下降。如果你能识别出哪些客户真正会响应，你的预算就能花得高效得多。

元学习器（meta-learner）试图为每一位客户单独估计处理效应。但这在实践中究竟是什么样子？

处理效应：ATE、CATE、ITE

要定义处理效应，我们求助于潜在结果框架。处理效应是由处理引起的结果差异：形式上写作 \(\tau = Y(1) - Y(0)\)，其中 \(Y(1)\) 是接受处理时的结果，\(Y(0)\) 是对照条件下的结果。例如，如果有优惠券时的潜在购买率是 20%，没有优惠券时是 10%，那么处理效应就是 10%。

接下来，有三个粒度层级：

  • ATE（平均处理效应）：对所有客户取平均的效应。“优惠券提高销售了吗？”
  • CATE（条件平均处理效应）：具有特定特征的客户的平均效应。“优惠券对 30 岁以下的城市客户效果更好吗？”
  • ITE（个体处理效应）：某一个具体个体的效应。在实践中无法观测，但 CATE 提供了我们所能得到的最佳估计。

这为什么重要？因为并非所有客户的行为方式都一样。一位对价格敏感的客户可能会扑向折扣，而一位品牌忠诚的客户反正也会按全价购买。如果你知道谁是谁，就可以把折扣定向投放到真正能带来额外销售的地方，而不是把利润白白让给无论如何都会购买的客户。

为什么需要元学习器

考虑这个问题：优惠券提高销售了吗？为了回答它，我们查看各类客户的数据，包括他们的属性（年龄、性别、地区）、处理（有优惠券或没有优惠券）以及结果（购买或未购买）。

\(Y(1)\) 这一列代表使用优惠券时的结果，而 \(Y(0)\) 代表没有优惠券时的结果。如果同一个人的这两列我们都有，计算处理效应就像两者相减一样简单。但难点在于，对每个个体我们只能观测到一个结果。

为了解决这个问题，我们使用元学习器。它们是一类机器学习框架，预测如果客户接受的是另一种处理会发生什么。通过填补这些缺失的反事实，我们可以为每个人估计处理效应。

S-Learner：从单个模型开始

S-Learner 中的“S”代表“Single”（单个），因为它依赖单个机器学习模型。我们用全部数据训练它，把处理指示变量当作一个普通特征放进去。要估计特征为 \(x\) 的客户的效应，我们向这一个模型索取两个预测：

\[\hat{Y}(1 \mid X=x) = \text{predicted outcome if treated}\]

\[\hat{Y}(0 \mid X=x) = \text{predicted outcome if not treated}\]

估计的处理效应是两者之差：

\[\hat{\tau}(x) = \hat{Y}(1 \mid X=x) - \hat{Y}(0 \mid X=x)\]

在代码中，S-Learner 从同一个模型得到这两个预测：一次把处理设为 1，一次把处理设为 0。

伪代码：

# Train a single model with treatment as a feature
X = df[['age', 'gender', 'location', 'treatment']]
y = df['sales']

model = xgb.XGBRegressor()
model.fit(X, y)

df['sales_treated'] = model.predict(X.assign(treatment=1))
df['sales_control'] = model.predict(X.assign(treatment=0))

df['treatment_effect'] = df['sales_treated'] - df['sales_control']
ATE = df['treatment_effect'].mean()

S-Learner 是最简单的起点，也常常是一个合理的基线。但它有一个关键弱点：如果处理效应相对其他特征而言很小，模型最终可能会忽略处理变量，尤其是在使用正则化的时候。这意味着你的 CATE 估计可能会偏向零。

T-Learner：两个独立的模型

T-Learner 中的“T”代表“Two”（两个）。我们不是训练一个模型，而是训练两个独立的模型：一个用实验组训练，一个用对照组训练。我们从实验组模型得到 \(\hat{Y}(1 \mid X=x)\)，从对照组模型得到 \(\hat{Y}(0 \mid X=x)\)，然后取差：

\[\hat{\tau}(x) = \hat{Y}(1 \mid X=x) - \hat{Y}(0 \mid X=x)\]

伪代码：

df_treated = df[df['treatment'] == 1]
df_control = df[df['treatment'] == 0]

# Train separate models, one per arm
model_treated = xgb.XGBRegressor()
model_treated.fit(df_treated[['age', 'gender', 'location']], df_treated['sales'])

model_control = xgb.XGBRegressor()
model_control.fit(df_control[['age', 'gender', 'location']], df_control['sales'])

df['sales_treated'] = model_treated.predict(df[['age', 'gender', 'location']])
df['sales_control'] = model_control.predict(df[['age', 'gender', 'location']])

df['treatment_effect'] = df['sales_treated'] - df['sales_control']
ATE = df['treatment_effect'].mean()

T-Learner 更灵活，因为每个模型可以为实验组和对照组学到不同的模式。但这有代价：它的方差可能很高，尤其是当实验组和对照组不平衡时。当你把两个预测相减时，两个模型的误差可能会叠加。

因此，S-Learner 简单，但倾向于低估效应。T-Learner 避开了这一特定的失败，代价是估计更嘈杂。接下来我们还能做什么？

更高级的元学习器

在 S 和 T 之外，还有几种更精细的方法针对它们的局限：

  • X-Learner：T-Learner 的一种扩展，为不平衡的处理组而设计。它先填补缺失的反事实，再用倾向得分加权将其合并。当一个组远大于另一个组时效果很好。
  • DR-Learner（双重稳健）：将结果建模与倾向得分估计结合起来。只要两个模型中任一个设定正确，估计就是一致的，故称“双重稳健”。
  • DML（双重机器学习）：使用交叉拟合来避免过拟合偏差，并有很强的理论保证。计算成本更高，在配套 Notebook 中大约比 S-Learner 慢一个数量级，但能给出正规的置信区间。

理论告诉我们每种方法本应优化什么。但真正的检验，是看它们在同一个数据集上的表现，在那里你能看到实际的差异。

示例：估计异质性的邮件效应

要观察这些方法的表现，我们需要一个能核对它们答案的数据集。这比听起来更难。在真实数据中，我们永远观测不到一位客户的真实处理效应，因此无法判断一个元学习器是找回了正确的模式，还是只是生成了看似合理的噪声。

我们用一个建立在 Kevin Hillstrom 的 MineThatData 邮件实验之上的半合成示例来解决这个问题。这是一个经典的营销数据集，64,000 名客户被随机分配到男装邮件、女装邮件或不发邮件三组。我们保留真实的客户特征（最近购买时间、购买历史、渠道等等），也保留“男装邮件对比不发邮件”这一二元对照的真实随机分配。只有结果是模拟的：我们定义一个基线购买概率，以及一个处理效应 \(\tau(x)\)，它对男装购买者、近期活跃客户和多渠道购物者更大。因为 \(\tau(x)\) 是我们自己写的，我们知道每位客户的真实 CATE，可以据此给每个学习器打分。

这是一个教学装置。目的不是比实验本身更好地估计平均效应，而是检验元学习器能否找回我们植入的异质性。

五个学习器全都找回了平均效应，更有用的是，也找回了细分群体层面的模式。下面的散点图把一个有代表性的学习器估计的 CATE 与真实效应进行比较。估计值聚集在 45 度线附近，因此客户被排在了大致正确的顺序上，纵向的离散则反映了二元结果的噪声。

在细分群体内取平均会让这种还原更清楚：按是否为男装购买者、最近购买时间、购买历史和渠道拆分后，估计效应紧贴真值，重现了我们植入在男装购买者、近期客户和多渠道购物者身上的更高响应。

信任 CATE 之前要检查什么

这个示例在设计上就很宽容：随机化的处理、完美的重叠，以及已知的答案。真实项目很少如此。在依据 CATE 估计采取行动之前：

  • 元学习器不会创造因果比较。它只是在你已经拥有的一个比较内部为效应的变化建模，因此在观测数据上，CATE 会继承底层比较所携带的每一个混杂问题。
  • 个体处理效应在真实数据中永远观测不到。我们在这里能给学习器打分，只是因为我们模拟了真值。
  • CATE 是模型估计，不是测量。在群体或细分群体层面读它，不要把它当成某一位客户的字面数字。
  • 核对平均值是否合理。如果平均估计 CATE 与实验上简单的均值之差相距很远，那就有问题。
  • 检查跨学习器的稳定性。如果 S、T、X 和因果森林在排序上意见不一，那么暂时一个都别信。
  • 留意重叠。在实验组和对照组客户不共存的地方，CATE 是外推，而不是估计。

要点

  • ATE 问的是处理是否有效；CATE 问的是对谁有效。元学习器在你已经拥有的因果比较内部估计这种差异，它们当中没有一个能修复你没有测量的混杂。
  • CATE 是群体层面的模型估计，真实效应在真实数据中永远观测不到，所以没有哪个学习器能凭名声赢得信任。要对照实验核对平均值、检查跨学习器的稳定性，并检查重叠。
