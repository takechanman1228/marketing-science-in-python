用 Python 做营销分析

关于中文版

用 Python 做营销分析，难点很少在代码上。难的是 选择一种既适合你面前的决策、又适合你实际拥有的数据的方法。 测量一次活动赚了多少、决定接下来联系谁、 制定一个价格，是三个不同的问题；拿错了 工具，得到的会是一个自信满满、却回答了一个没人问过的问题的数字。

本页把常见的营销分析问题对应到 Marketing Science in Python 中处理该问题的章节。这些章节大多配有一个 可运行的 Python notebook。

测量营销是否起了作用

这个问题是因果性的：本来会发生什么？先从 因果思维 开始，了解选择偏差和 混杂，然后让数据来决定设计。当你可以随机化时， A/B 测试设计 讲统计功效、样本量，以及 在上线前设定停止规则。当你不能随机化时， 准实验 讲双重 差分、断点回归和合成控制。在完全没有对照 组的情况下，基于时间序列的因果影响分析 则转而从干预前的时期构建一个反事实。

决定要定向哪些客户

平均效应掩盖了到底是谁做出了响应。 估计处理效应的元学习器 估计 效应在不同客户之间如何变化，而 用于定向投放的增益建模 把它 变成一份目标名单，名单上是会被活动说服的人，而不是 无论如何都会购买的人。

理解你的客户群

客户细分 从十分位和 RFM 逐步深入到行为聚类和基于嵌入向量的细分群体，最终得到一个 你的 CRM 和广告平台可以使用的 segment_id。 客户终身价值建模 用 BG/NBD 和 Gamma-Gamma 模型预测 一个客户值多少钱，这正是把获客预算 变成一个你能为之辩护的数字的关键。

制定价格与品类组合

价格弹性与定价决策 从交易数据估计需求曲线，并针对边际贡献 而不是销量进行优化。 产品品类组合优化 决定该砍掉哪些产品，估算购物者转向替代品时 面临风险的收入规模，并在推广到每家门店之前验证这一决定。

预测与情景规划

销售预测与情景规划 构建一个基线预测，用滚动起点对其回测，并把它 转换为在不同营销情景下达成目标的概率。

测量与分配媒体投入

媒体测量问题 解释为什么归因、营销组合建模和实验回答的是 不同的问题。 构建并优化一个 MMM 讲 广告滞留效应、饱和效应，以及用 Google Meridian 做预算分配。 增量效应实验 用地理测试测量真实的提升， 用实验校准 MMM 把这些 证据反馈回模型，而 当归因、MMM 与实验结果不一致时 给出了预算决策的一套流程。

用到的 Python 库

statsmodels 和 SciPy 用于检验、功效分析和结构时间序列， EconML 用于处理效应和增益，scikit-learn 和 LightGBM 用于 聚类和梯度提升，BERTopic 和 sentence-transformers 用于 基于嵌入向量的细分群体，PyMC-Marketing 用于客户终身价值，Prophet、 mlforecast 和 TimesFM 用于预测，Google Meridian 用于营销组合 建模。Notebook 与代码 按部分和主题列出了 书中的每一个 notebook。
