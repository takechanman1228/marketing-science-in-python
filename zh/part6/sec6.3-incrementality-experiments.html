6.3 增量效应实验

关于中文版

第 6.2 节的 MMM 建议将 Google Search 支出削减 30%。要直接照做吗？先等等。过去三年，Search 支出几乎没变，模型没有见过支出变化后的情况。它估计，Search 每多花一美元的回报在 0.4 到 9.5 之间。

我们需要知道 Search 的增量效应，也就是没有这些广告就不会产生的收入。有些人搜索店铺名称后点击广告，但即使没有广告，他们也可能点击下方的自然搜索结果并购买。购买记录无法区分这两种情况。

可以用实验来回答。我们在部分市场将 Search 支出削减 30%，在相似市场保持支出不变，再比较收入。支出未变的市场反映了不削减预算时可能发生的情况，也就是反事实。这种设计称为地理实验。

实验结果用增量 ROAS（iROAS） 表示，即收入变化除以支出变化。对于削减预算的实验，它表示每节省一美元损失多少收入。

配套笔记本： sec6.3_geo_experiment.ipynb 在包含 40 个市场的合成面板上运行实验。真实效应预先植入数据，因此可以用它核对下面的每个估计值。

设计实验

实验开始前，要确定比较哪些市场、什么结果足以支持削减预算，以及实验持续多久。

选哪些市场。 实验比较成对的相似市场。按规模和历史销售额配对，例如选择销售额相近的两个州，再掷硬币决定在哪个市场削减预算。配对能减少噪声，掷硬币则实现了随机分配。由于削减预算的市场不是由我们选定的，两组的差异可以归因于预算削减。

面板包含 40 个市场、96 周的历史数据。笔记本选出收入走势最接近其余业务的 16 个市场，按规模排序，组成八个匹配对（图 1）。每对中，一个市场将 Search 支出削减 30%，另一个保持原有支出。

配对市场不应共享顾客或广告覆盖范围。如果在实验市场看到广告的人转而在邻近的对照市场购物，一部分效果就会进入对照组，使估计值向零收缩。这叫作溢出效应，无法在分析阶段修正。

什么结果支持削减预算。 如果损失的收入所对应的价值低于节省的费用，削减预算就划算。设贡献利润率为 \(m\)，每花一美元需要带来 \(1/m\) 美元的收入才能盈亏平衡。利润率为 40% 时，Search 每花一美元需要带回 $2.50。这就是 iROAS 的盈亏平衡点。

实验前，按 iROAS 的 95% 置信区间制定决策规则：

  • 整个区间低于 2.50：削减预算。
  • 整个区间高于 2.50：保持预算。
  • 区间跨过 2.50：维持全国预算方案，开展后续实验。

做多久。 时长取决于削减幅度和市场波动。大幅削减的影响几周内就可能看出来；小幅削减需要更长时间才能与每周的正常波动区分开。常见的起点是在四到八周内将支出调整 20% 到 50%。

笔记本通过模拟检验实验设计。它把启动日期设在过去，在历史数据中植入已知的 iROAS，再统计分析有多少次能检出这个效应。检出比例就是实验的统计功效。能在 80% 的模拟中检出的最小效应，称为最小可检测效应（MDE）。四周内削减 20% 时，MDE 为 0.70；八周内削减 30% 时，MDE 为 0.40，因此我们采用后一种设计。

MDE 衡量实验能否区分效应和零。我们的决策需要区分效应和 2.50，因此笔记本也模拟了决策规则。真实 iROAS 为 1.5 时，99% 的模拟建议削减。真实值为 2.0 时，只有 21% 建议削减，其余建议维持预算。真实值越接近盈亏平衡点，实验就越需要延长或扩大规模。

要把两个阈值分开看。即使 iROAS 小到无法与零区分，只要整个区间远低于 2.50，也足以支持削减预算。

市场名单、日期、支出计划、估计方法、盈亏平衡点和随机种子都在实验前确定。如果能在看到结果后更改设计，就可能把实验调整到某人想要的结论。

用双重差分衡量效果

实验从 2024 年 2 月 5 日开始。八个实验市场将 Search 支出削减 30%，持续八周，其余条件不变。实验期间要记录实际支出，因为 iROAS 根据实际节省的费用计算。等满八周再看结果，因为过早查看会受到更多噪声干扰，也更容易出现假阳性。

为什么不能只做前后对比。 最简单的分析是比较实验市场在实验期间与之前八周的收入。得到的 iROAS 为 0.44，似乎每节省一美元只损失 44 美分收入。但受季节影响，当时所有市场的收入都在增长，连预算没变的市场也一样。季节性增长抵消了大部分削减造成的损失，所以前后对比给出的数值偏低。

双重差分。 对照市场经历了同样的季节变化，但没有削减预算。第 3.3 节介绍的双重差分（DiD）利用这些市场扣除季节影响。先计算每个实验市场的收入变化，再减去与之配对的对照市场的收入变化：

\[ \text{effect} = (\text{test}_{\text{after}} - \text{test}_{\text{before}}) - (\text{control}_{\text{after}} - \text{control}_{\text{before}}) \]

在回归中，这个效应是 treat 和 post 交互项的系数：

import statsmodels.formula.api as smf

model = smf.ols("revenue ~ treat * post", data=analysis).fit(
    cov_type="cluster",
    cov_kwds={"groups": analysis["pair"]},   # one coin flip per pair
)

系数表明，每个实验市场相对于对应的对照市场，每周损失约 $9,900 的收入。八个市场、八周合计减少收入 $633,069，节省 Search 支出 $421,906。两者相除得到 iROAS 1.50，标准误为 0.257，95% 置信区间为 [0.892, 2.109]。

数据是合成的，因此可以核对真实值：面板中植入的 iROAS 为 1.500。笔记本做了两项额外检验，结果一致。合成对照对未接受干预的市场加权，使其贴合实验开始前的实验市场，得到 1.486（图 2）。安慰剂检验在每对市场内交换实验组与对照组。256 种分配中，只有 2 种得到至少与我们一样大的估计值（p = 0.008）。

与盈亏平衡点比较。 Search 每少花一美元，收入约减少 $1.50，盈亏平衡点则为 $2.50。整个置信区间都低于 2.50，因此按事先确定的规则，应削减预算。具体来说，节省 $100 的 Search 支出会减少约 $150 收入。贡献利润率为 40%，因此少了 $60 贡献利润，企业净得 $40。

该效应具有统计显著性（p = 0.008），说明 Search 广告确实带来了收入。但在当前支出水平下，广告带来的收益低于成本，决策取决于这项比较。

实验在八个市场将预算削减 30%，持续八周。这些市场占全国 Search 支出的 19.9%。结果表明，Search 支出中最后的 30% 不划算。至于节省的预算应该投到哪里，这次实验没有改变其他渠道的支出，无法回答。第 6.4 节会把结果带回 MMM 来回答这个问题。

要点

  • 增量效应是没有广告就不会产生的收入。地理实验通过改变部分市场的支出，并用相似市场作为反事实来估计它。
  • 启动前确定市场、决策规则和实验时长。通过模拟检查实验除了能区分 iROAS 和零，还能区分 iROAS 和盈亏平衡点。
  • 用盈亏平衡 iROAS 判断结果。Search 广告确实带来了收入，但 1.50 的 iROAS 不足以覆盖广告成本，因此应该削减预算。
