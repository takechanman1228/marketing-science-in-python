# `data/generated/part6/sec6.2-mmm/` — MMM synthetic dataset

Synthetic marketing-mix-modeling dataset used by **Chapter 6.2 (Fundamentals)** and
**Chapter 6.4 (Calibration)** of the book.

## Files

| File | Description |
|---|---|
| `mmm_synthetic_data.csv` | Weekly media spend + exposure + outcome panel (5 channels, 157 weeks) |
| `mmm_ground_truth_roi.csv` | Known response curve per channel: true average ROI, true marginal ROI, the ROAS of a 30% cut sustained for eight weeks, and the adstock and saturation parameters behind them |

## Provenance

Generated by [PySiMMMulator](https://github.com/RyanAugust/PySiMMMulator) via the
companion script, which then rebuilds the outcome through geometric adstock and
Hill saturation so the panel has real response curves:

```
pip install pysimmmulator==0.5.1
PYTHONPATH=src python notebooks/part6-media-optimization/mmm_data_generation.py
```

PySiMMMulator is pinned and installed separately because only the generator
needs it. The `PYTHONPATH` points `msbook` at this checkout, so the CSVs are
rewritten here rather than in whichever clone was pip-installed last. Rerun the script if you want to regenerate the dataset (it writes
back to this directory). The generator script is the source of truth; the CSVs here are
bundled for reproducibility so readers can re-fit the model without running the
generator.

## Load via msbook

```python
from msbook.data import load_mmm_synthetic
from msbook.paths import DATA_DIR
import pandas as pd

df = load_mmm_synthetic()
truth_df = pd.read_csv(DATA_DIR / "generated" / "part6" / "sec6.2-mmm" / "mmm_ground_truth_roi.csv")
```
