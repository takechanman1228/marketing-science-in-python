# `data/generated/part6/sec6.2-mmm/` — MMM synthetic dataset

Synthetic marketing-mix-modeling dataset used by **Chapter 6.2 (Fundamentals)** and
**Chapter 6.3 (Calibration)** of the book.

## Files

| File | Description |
|---|---|
| `mmm_synthetic_data.csv` | Weekly media spend + exposure + outcome panel (5 channels, ~52 weeks) |
| `mmm_ground_truth_roi.csv` | Known true ROI per channel — used to validate that Meridian recovers ground truth |

## Provenance

Generated by [PySiMMMulator](https://github.com/leehananne/PySiMMMulator) via the
companion script:

```
notebooks/part6-media-optimization/mmm_data_generation.py
```

Rerun the script if you want to regenerate the dataset (it writes back to this
directory). The generator script is the source of truth; the CSVs here are
bundled for reproducibility so readers can re-fit the model without running the
generator.
