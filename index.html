Marketing Science in Python

A Practitioner’s Guide to Causal Inference, Marketing Mix Modeling, Pricing, Forecasting, and Customer Analytics

A practitioner’s guide to causal inference, Marketing Mix Modeling, pricing, forecasting, customer analytics, and media measurement with runnable Python notebooks.

Preface

Last month’s campaign drove a spike in sales, and the team is celebrating. But was it really the campaign? Temperatures rose that same week. A competitor ran out of stock. An influencer posted about the product. Even if sales increased, did the campaign actually bring in valuable new customers, or just shift purchases that would have happened anyway?

Even in 2026, these questions are still hard to answer. AI has sped up the creative side of marketing, like generating ad copy, producing banners, and building landing pages. Coding assistants have made it much faster to write code and run analyses. But the decision side has not kept up. Questions like “Did it work?” and “What should we do next?” remain just as challenging. In marketing, you can never measure or control every variable that matters. You have to make decisions under uncertainty, often on a tight timeline. This is where human judgment is most important.

This book is a practical guide to making marketing decisions more reliable, even when the data is messy. Three things set it apart:

  • Python notebooks are provided. Each hands-on chapter in Parts 3–6 has a companion notebook using public datasets. Each notebook is committed with its outputs, so you can read the results on GitHub.
  • The book focuses on core marketing problems. It covers the marketing problems where data science is most useful in practice. It is not a model catalog.
  • Modern Python libraries are used. The book uses tools such as Google Meridian, PyMC-Marketing, EconML, Nixtla, and BERTopic. The goal is not to showcase libraries, but to explain what problem each tool helps solve.

This is the guide I wish I had when I started applying data science to marketing.

Who This Book Is For

I wrote this book with three readers in mind:

  • Data scientists moving into marketing. You are comfortable with machine learning, but want to tackle marketing-specific questions like experiment design, uplift modeling, customer lifetime value (CLV), pricing, and marketing mix modeling (MMM), where generic ML playbooks fall short.
  • Marketing analysts who want to see the implementation. If you have read articles about MMM and causal inference, this book walks through the working code from start to finish.
  • Business professionals who use models without building them. You can skip the code and focus on the problem framing at the start of each chapter. You will see where each model applies and where it breaks, such as why a discount can boost revenue but erode margin, or why an MMM needs experimental calibration.

This is not an introduction to Python or machine learning. It is not a theory textbook, and it is not a book of digital marketing tactics. Instead, it sits at the intersection: data science applied to marketing decisions.
