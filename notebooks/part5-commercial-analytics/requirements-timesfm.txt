# Optional: the TimesFM row of the Chapter 5.3 backtest.
#
# Kept out of requirements.txt on purpose. TimesFM needs PyTorch and downloads a
# foundation-model checkpoint on first use, which is a large ask for a reader who
# only wants the chapter's other five models. The committed .ipynb already carries
# every TimesFM output, so you need this only to re-run that row yourself:
#
#   pip install -r notebooks/part5-commercial-analytics/requirements-timesfm.txt
#
# An exact pin, unlike the >= floors everywhere else in this repo: the numbers
# this produces are committed, quoted in the chapter to one decimal of a
# percent, and checked against it by the test suite, so a version bump has to
# be a deliberate act. The chapter uses the
# TimesFM 2.5 checkpoint (Apache-2.0), not 3.0, whose weights are restricted to
# non-commercial, non-production use.
#
# torch is deliberately NOT pinned here. This file is installed into an existing
# environment that other chapters share, and a hard pin would silently downgrade
# torch under Part 4's semantic segmentation. timesfm constrains it well enough;
# the committed numbers were produced with torch 2.10.0.
timesfm[torch]==3.0.0
