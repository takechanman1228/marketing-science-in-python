6.3 インクリメンタリティ実験

日本語版について
このページは英語版 Marketing Science in Python のAI翻訳です。英語版を正本とし、差異がある場合は英語版を優先してください。コード、Notebook、画像内の文字は英語のままです。 英語版を読む

Section 6.2のMMMは、Google Searchの30%削減を推奨しました。そのまま実行してよいでしょうか。まだです。Search支出は3年間ほとんど変わらなかったので、モデルは支出が動いたときに何が起きるかを一度も見ていません。次の1ドルがいくら生むかについてのモデルの推定は、0.4から9.5まで広がっています。

知る必要があるのは、Searchのインクリメンタリティ（増分効果）、つまり広告がなければ生じなかった売上です。店名で検索して広告をクリックした人は、すぐ下の通常の検索結果をクリックして、同じように買ったかもしれません。購入記録からは、この2つを区別できません。

確かめる方法は実験です。一部の市場でSearchを30%削減し、似た市場では変えずに、売上を比べます。変えなかった市場は、削減しなかった場合に何が起きたかを示します。これを反実仮想と呼びます。この設計が地域実験（geo experiment）です。

結果は増分ROAS（iROAS）で表します。売上の変化を支出の変化で割った値です。削減の場合は、節約した1ドルあたりに失った売上になります。

付属ノートブック： sec6.3_geo_experiment.ipynbは、40市場の合成パネルで実験を実行します。真の効果をデータに埋め込んであるので、以下の推定値はすべて真値と照らして確認できます。

テストを設計する

テストを始める前に、3つのことを決めます。どの市場を比べるか、どんな結果なら削減を正当化できるか、どれだけの期間実施するかです。

どの市場か。 テストでは、似た市場のペアを比べます。各市場を、規模と売上の推移が似た市場と組にします。たとえば売上の近い2つの州です。そして、どちらを削減するかをコイン投げで決めます。似た市場を組にすると、ノイズが減ります。コイン投げは無作為化です。どちらの市場を削減するかを私たちが選ばないので、2つの市場の差を削減の効果とみなせます。

パネルには40市場、96週間の履歴があります。ノートブックは、売上が事業全体の動きに最も近い16市場を残し、規模の順に並べて、8組のマッチドペアを作ります（図 1）。各ペアで、一方の市場はSearchを30%削減し、もう一方は通常どおり支出します。

ペアにした市場は、買い物客やメディアを共有していてはいけません。ある市場で広告を見た人が隣の対照市場で買い物をすると、効果の一部が対照群に漏れ、推定値はゼロの方向へ縮みます。これをスピルオーバーと呼び、分析では補正できません。

どんな結果なら削減を正当化できるか。 削減によって失う売上の価値が、節約できる金額より小さければ、削減する価値があります。貢献利益率が\(m\)なら、支出1ドルは\(1/m\)の売上を返して損益分岐になります。利益率40%なら、Searchの1ドルは$2.50を返す必要があります。これが損益分岐iROASです。

意思決定ルールは、iROASの95%信頼区間を使って、テストの前に書いておきます。

  • すべて2.50より下：削減する。
  • すべて2.50より上：予算を維持する。
  • 2.50をまたぐ：全国計画を保留し、追試を行う。

どれだけの期間か。 必要な長さは、削減の大きさと、市場のノイズの大きさで決まります。大きな削減は数週間で見えてきます。小さな削減は、通常の週ごとの変動と見分けるのに時間がかかります。4〜8週間で20〜50%の支出変更が、一般的な出発点です。

ノートブックは、この設計をシミュレーションで確かめます。過去の日付にテストを開始したことにして、既知のiROASを履歴に埋め込み、分析がそれを見つけられた回数を数えます。効果を見つけられた割合が、テストの検出力です。80%の確率で見つけられる最小の効果が、最小検出可能効果（MDE）です。4週間の20%削減ではMDEは0.70です。8週間の30%削減ではMDEは0.40なので、この設計を使います。

MDEが示すのは、テストが効果をゼロと見分けられるかどうかです。ここでの意思決定は2.50と見分けられるかどうかにかかっているので、ノートブックは意思決定ルールもシミュレーションします。真のiROASが1.5のとき、ルールは99%の確率で「削減」を返します。2.0のときは、「削減」を返すのは21%だけで、それ以外は「保留」です。真値が損益分岐に近い場合は、テストをより長く、またはより大きくする必要があります。

この2つの基準は分けて考えると分かりやすくなります。ゼロと見分けられないほど小さいiROASでも、区間は2.50を大きく下回るので、削減を正当化するにはそれで十分です。

これらの選択はすべて、開始前に固定します。市場リスト、日付、支出計画、推定方法、損益分岐、乱数シードです。結果が出た後で設計を変えられると、誰かの望む答えに寄せられてしまいます。

差分の差分法で効果を測る

テストは2024年2月5日に始まります。8つのテスト市場でSearch支出を8週間、30%下げ、それらの市場ではほかに何も変えません。テスト中は、実際に配信された支出を記録します。iROASは、実際に減らした支出から計算するからです。また、8週間が終わるまで結果は見ません。途中で見るとノイズが大きく、偽陽性が増えるからです。

前後比較がうまくいかない理由。 最も単純な分析は、テスト市場のテスト期間中の売上を、その直前の8週間と比べることです。この方法ではiROASは0.44になり、節約した1ドルあたり44セントしか売上を失わないことになります。しかしこの時期は、何も変えていない市場も含め、すべての市場で季節要因により売上が伸びていました。季節的な伸びが削減による損失の大半を打ち消したため、前後比較の数値は小さすぎます。

差分の差分法。 対照市場は、削減なしで同じ季節を過ごしました。Section 3.3で紹介した差分の差分法（DiD）は、対照市場を使って季節的な動きを取り除きます。各テスト市場の売上の変化から、ペアの対照市場の変化を引きます。

\[ \text{effect} = (\text{test}_{\text{after}} - \text{test}_{\text{before}}) - (\text{control}_{\text{after}} - \text{control}_{\text{before}}) \]

回帰では、この効果はtreatとpostの交互作用の係数になります。

import statsmodels.formula.api as smf

model = smf.ols("revenue ~ treat * post", data=analysis).fit(
    cov_type="cluster",
    cov_kwds={"groups": analysis["pair"]},   # one coin flip per pair
)

係数から、各テスト市場は対照市場と比べて週あたり約$9,900の売上を失ったことが分かります。8市場・8週間で、削減は$633,069の売上を失い、$421,906のSearch支出を節約しました。この2つを割ると、iROASは1.50、標準誤差は0.257、95%信頼区間は[0.892, 2.109]です。

データは合成なので、真値と比べられます。パネルに埋め込んだiROASは1.500です。ノートブックにある2つの追加確認も、同じ答えを出します。合成コントロールは、処置していない市場を重みづけして組み合わせ、開始前のテスト市場に合わせる方法で、1.486になります（図 2）。プラセボテストは、各ペア内でテストと対照を入れ替える方法で、起こりえた256通りの割り当てのうち、今回と同じ大きさの推定値が出るのは2通りだけです（p = 0.008）。

損益分岐と比べる。 Searchから削った1ドルは約$1.50の売上を失わせ、損益分岐は$2.50です。信頼区間の全体が2.50を下回っているので、テスト前に書いたルールにより、削減は正当化されます。金額で言えば、Searchの支出を$100節約すると売上が約$150減り、利益率40%ならその売上の貢献利益は$60です。差し引き$40の改善になります。

効果は統計的に有意なので（p = 0.008）、Search広告は確かに売上を生んでいます。ただし現在の支出水準では、生む売上がコストを下回っており、意思決定はこの比較で決まります。

実験が対象としたのは、全国のSearch支出の19.9%を占める8市場での、8週間の30%削減です。この実験から、Search支出の最後の30%は採算が合わないことが分かります。節約した予算をどこに回すべきかは分かりません。ほかのチャネルは変えていないからです。Section 6.4では、この結果をMMMに戻して、その問いに答えます。

重要なポイント

  • 増分効果とは、広告がなければ生じなかった売上である。地域実験は、一部の市場で支出を変え、似た市場を反実仮想として使うことで、これを測る。
  • 市場、意思決定ルール、テスト期間を開始前に決め、テストがiROASをゼロだけでなく損益分岐とも見分けられるかを、シミュレーションで確かめる。
  • 結果はゼロではなく、損益分岐iROASと比べて判断する。Searchの広告は確かに売上を生んでいたが、iROASは1.50でコストを下回っていたので、削減は正当化される。
