3.4 時系列による因果インパクト

日本語版について
このページは英語版 Marketing Science in Python のAI翻訳です。英語版を正本とし、差異がある場合は英語版を優先してください。コード、Notebook、画像内の文字は英語のままです。 英語版を読む

前の章のデザインには、どれにも対照群がありました。ディスプレイを導入した店舗と、導入しなかった店舗がありました。一つの市場でキャンペーンを行い、ほかでは行いませんでした。この章では、対照群が一つもない場合を扱います。

全国規模のテレビキャンペーンを8週間実施し、売上が増えました。しかし、すべての市場がキャンペーンへ接触したため、比較できる非処置市場がありません。キャンペーンがなければ、売上はどうなっていたでしょうか？

この章の役割は一つです。欠けている「キャンペーンなし」の経路を構築し、キャンペーンの測定基準として十分に信頼できるかを判断します。構築には15行のコードしか使いません。それを信頼できるかの判断が、章の残りすべてです。

反実仮想を構築する

中心となる考え方： キャンペーンがなければ観察したはずの売上を予測する。効果は、観測売上からその予測を引いたもの。

対照群がなければ、時間から比較対象を得る必要があります。キャンペーンの影響が入り込まないよう、キャンペーン前の売上に時系列モデルを当てはめます。キャンペーン期間を通じてモデルを先へ予測します。その予測が反実仮想であり、実際に起きたこととの差が推定効果です。

予測では対照系列を使うことができますが、対照群ではないことを明確にしておく必要があります。対照群は、同じ種類の非処置単位、たとえばディスプレイを導入しなかった店舗です。対照系列は予測変数であり、カテゴリー需要指数やメディア出稿のない同系統の商品ラインなど、キャンペーンが影響できなかったあらゆる系列です。ブランドと比較するものではありません。キャンペーン中に市場がどう動いていたかを予測へ伝えます。

最もよく知られた実装はCausalImpactです。 GoogleがRパッケージとして公開し、Brodersenらが2015年の論文で説明しました。因果推論の文献では、同じデザインを中断時系列と呼びます。 Pythonへの移植版（tfp-causalimpact、CausalPy の InterruptedTimeSeries）もあります。この章では同じ論理を statsmodels で直接構築し、すべての仮定が見えるようにします。

これは前章のはしごの最後の段です。表は、段を上る途中で何が変わったかを示します。

観察できなかった売上を構築する3つの方法。
デザインの特徴 DiD 合成コントロール CausalImpact
必要な非処置単位 対照群 ドナープール なし。対照系列は比較対象ではなく予測変数
比較対象の由来 対照群の時間変化 ドナープールの加重合成 系列自身の過去からの予測
検証できない仮定 平行トレンド 事前期間の適合が継続する 対照系列が処置の影響を受けていない

例に使うのは、全国規模のCPGブランドです。4年間の週次売上、8週間のテレビ・PRキャンペーン、その後20週間の観察があります。対照系列は、サブカテゴリー需要指数と、メディア出稿のなかった同系統の商品ラインの2つです。合成データなので、真の「キャンペーンなし」の経路が分かっています。コードを書く前に、分析概要を定めます。

ノート分析概要
  • ビジネス上の問い： キャンペーンはどれだけの増分売上を生んだか？
  • アウトカム： 全国の週次売上。
  • 処置： 8週間のテレビ・PRキャンペーン。一つの複合介入として測定する。
  • 推定対象： 開始後28週間における累積増分売上。持続効果と、その後の反動を含む。

最後の行は意思決定であり、誰も数値を見る前のこの時点で行います。そのため、以下の予測は28週間実行され、章の後半にある報告期間の節は選択ではなく確認になります。

反実仮想を構築するコードは次のとおりです。

import numpy as np
from statsmodels.tsa.statespace.structural import UnobservedComponents

# 1. Fit on the PRE-period only. The campaign is deliberately absent.
model = UnobservedComponents(
    np.log(y_pre),
    level="lltrend",                                   # level and slope
    freq_seasonal=[{"period": 52, "harmonics": 2}],    # annual shape
    exog=np.log(x_pre),                                # untouched controls
)
res = model.fit(disp=0)

# 2. Simulate 1,000 no-campaign paths across the 28 post-period weeks
horizon, draws = len(y_post), 1000
paths = np.exp(
    np.asarray(res.simulate(horizon, repetitions=draws, anchor="end",
                            exog=np.log(x_post))).reshape(horizon, draws)
)

# 3. Effect = observed minus counterfactual. The point estimate and the
#    interval come from the same draws, so both summarize one distribution.
counterfactual = paths.mean(axis=1)
weekly_effect = y_post - counterfactual
cumulative = weekly_effect.sum()
lo, hi = np.percentile((y_post[:, None] - paths).sum(axis=0), [2.5, 97.5])

このコードでは、3つの選択が重要です。モデルは事前期間だけに当てはめるため、キャンペーンが自身のベースラインを汚染することはありません。キャンペーンのリフトと季節性はいずれも乗法的なので、売上は対数でモデル化し、シミュレーションした経路は合計する前にドルへ戻します。また、対照系列を回帰変数として入れるため、予測はキャンペーン中に市場で何が起きたかを把握できます。モデルにトレンド項が必要か、そもそも対照系列が必要かは、好みで決めることではありません。次の節で測定によって決めます。

測定前に反実仮想を検証する

この手順は省略できません。報告する効果は観測値から予測値を引いたものなので、予測誤差1ドルごとに、偽の効果が1ドル生じます。キャンペーンの測定に予測を使う前に、何も起きなかった期間を予測できることを示す必要があります。3つの確認を行い、すべて事前期間だけで実施します。

予測をバックテストする

モデルは非処置の世界を予測できるでしょうか。事前期間内のある過去の日付にキャンペーンが始まったと仮定します。その日付より前のデータにモデルを当てはめ、次の28週間を予測し、実際に起きたことと比較します。複数の日付から繰り返します。28週間とするのは分析概要の推定対象だからです。8週間では問題なく見えるモデルも、28週間では崩れることがあります。

何も起きなかった事前期間の9つの窓に対する、起点をずらした検証。
仕様 予測誤差 バイアス 区間の被覆率
季節ナイーブ 7.96% -5.83% n/a
水準、対照なし 5.54% -1.32% 99.6%
水準＋対照 2.62% -0.60% 96.8%
トレンド＋対照 2.43% +0.48% 87.7%

この表から判断できます。トレンド＋対照の誤差とバイアスが最小なので、この仕様を使います。その過程で2つの点が重要です。対照系列によって誤差が半分になったため、このデータでは入れる価値があります。また、この予測期間ではトレンド項が重要です。ブランドはサブカテゴリーより速く成長しており、傾きのないモデルはその差をキャンペーンの効果として計上します。

プラセボ介入

何も起きなかったときに、このデザインが効果を作り出してしまわないでしょうか。キャンペーンがなかった事前期間から、たとえば120週目を選びます。その週にキャンペーンが始まったと仮定し、分析全体を実行します。正しい答えはゼロなので、得られる結果は、このデザインがノイズだけから生み出すものです。これをプラセボ介入と呼びます。上の9つのバックテスト期間は、9つのプラセボにもなります。ここで最大のプラセボ効果は$636kで、9つのうち1つでは区間がゼロを除外しました。両方の数値を保持します。キャンペーンの推定値は、これらを上回る必要があります。

対照系列が役立つことを確認する

対照系列は本当に予測を改善するでしょうか。このデータではバックテストがすでに「はい」と答えていますが、その価値を確認しておきます。市場が安定している場合、対照系列によって区間の幅は12分の1になります。キャンペーンのうち3週間にカテゴリー全体の落ち込みが起きた場合、反実仮想も市場とともに落ち込むため、対照系列ありの推定値は真値の1.3%以内になります。対照系列がなければ、同じ落ち込みがキャンペーンのせいになり、推定値は真値を21%下回ります。優れた対照系列は、全体へ影響するショックを吸収し、モデルがキャンペーンと取り違えないようにします。

これは、キャンペーンが対照系列へ影響しなかった場合に限って機能します。データからは検証できない仮定であり、推定値を信頼すべきでない場合で詳しく扱います。

キャンペーン効果を推定する

ここで初めてキャンペーン期間を使います。選択した仕様を事前期間全体に当てはめ、先へ予測します。その結果が、一度限りのキャンペーンを提示する標準的な方法となった3パネルのグラフです。観測値と反実仮想、週次の差、累積値を示します。

報告期間を選ぶ

分析概要では、推定対象を28週間に固定しました。それが重要だった理由を説明します。累積パネルを見ると、曲線は8週間の出稿中に上昇し、持続効果によってその後数週間も上昇を続け、前倒しされた需要の反動が起きると下降します。どれも妥当に聞こえる3つの期間から、3つの異なる数値が得られます。

同じモデルと同じキャンペーンを、3つの期間で評価した結果。
報告期間 推定値 95%区間 真値 誤差
出稿期間のみ、8週間 $1,157k $844k〜$1,446k $1,291k -10.4%
出稿期間と持続効果、12週間 $1,603k $1,174k〜$1,996k $1,574k +1.8%
事後期間全体、28週間 $1,164k $411k〜$1,890k $1,124k +3.6%

3つの推定値は、それぞれが対象とする期間については正確です。反動を含めるのは最後の推定値だけなので、分析概要へ答えるのも最後の推定値だけです。曲線の頂点である12週目で止めると、全期間の答えを38%過大評価します。モデルが間違っていたのではなく、期間が間違っていました。そのため、誰かが曲線を見る前に、分析概要で期間を定めます。

区間をどの程度信頼するか

グラフ上の帯は、当てはめたモデルを固定し、そのノイズを先へ伝播させています。そのため、実際の不確実性全体ではなく、その下限を示します。解釈には2つの情報が役立ちます。第一にプラセボの結果です。$1,164kという推定値は、このデザインが生み出したすべてのプラセボ効果より大きく、最大のプラセボは$636kでした。意思決定と同じ単位なので、p値より有用な説明です。第二に、以下の監査です。

ノート深掘り：このデザインは実際どの程度優れているか？

Notebookでは、選択した仕様を新しい200個の合成データセットで再実行し、毎回真値に照らして評価します。名目上の95%区間が真値を含むのは90%です。真の効果を有意と判定するのは60%です。真の効果がゼロのとき、有意と判定するのは9%です。これはモデルが弱いのではありません。測定状況が弱いのです。処置系列は一つ、無作為化はなく、効果はノイズに比べて小さい状況です。意思決定にそれ以上の確度が必要なら、次回は地域実験を実施します（Chapter 6.3）。

推定値を信頼すべきでない場合

この分析を壊す要因は3つあります。そのうち2つはデータに痕跡を残しません。

キャンペーンが対照系列へ影響した

対照系列の予測力が高いほど、キャンペーンがそこへ届いた可能性も高くなります。サブカテゴリー指数はモデルの説明力の大半を担っています。だからこそ、そのサブカテゴリーの大手ブランドによる全国キャンペーンは、指数を脅かします。ブランドのリフトの35%が指数へ漏れると、推定値は真の効果の65%しか捉えず、区間もゼロを除外しなくなります。効果のあったキャンペーンが、結論なしと読まれるようになります。それでも、すべての診断を通過します。事前期間の適合はきれいで、区間は狭く、バックテストも同じに見えます。破られた仮定はデータの外にあります。確認する唯一の方法は、キャンペーンを実施した人に、何へ影響した可能性があるかを尋ねることです。

事前期間の関係が崩れた

4年間続いた関係も止まることがあります。競合が参入し、事後期間にサブカテゴリーを5%成長させたものの、このブランドはその成長を共有しなかったとします。対照系列は市場が改善したと示し、反実仮想は上昇します。その結果、真の効果がプラス$1,124kであるのに、推定値はマイナス$460kになります。この章で真値が区間の外に出る唯一のシナリオであり、構造上、事前期間のデータからは検証できません。これはDiDが求める規律と同じです。出力の質は、対照系列が以前と同じように動き続けたという主張の質を超えられません。

予測が最初から十分でなかった

3つ目の失敗は、探せば痕跡を残します。同じ仕組みを実際のDunnhumby店舗データで実行します。1店舗の週次売上を取り、最後の12週間を1.15倍し、ほかの4店舗を対照系列として、埋め込んだリフトの復元を試みます。

リフトは復元されます。埋め込んだ1,775単位が1,833として推定され、区間はゼロを除外します。対照系列を使った分析が成功したと簡単に報告できそうです。

しかし、成功ではありません。対照系列を正当化した店舗間相関は0.45でしたが、Dunnhumbyのパネルは小さく始まって成長するため、需要とは無関係な理由で全店舗が一緒に上昇します。その導入期の増加を除くと、相関は0.01へ下がります。バックテストで結論が出ます。4つの対照店舗を追加しても、予測誤差は13.7%から13.8%になり、まったく改善しません。狭くなった区間が罠です。予測が改善していなくても、追加の回帰変数はサンプル内の変動を吸収し、帯を狭めます。区間が狭いことは、対照系列が役立った証拠ではありません。より良いバックテストが証拠になります。この数値を生んだのは、1店舗自身の直近の水準を投影したものであり、13.7%の予測誤差は因果的な主張を支えるには弱すぎます。そう伝えること自体が分析結果です。

実践的なワークフロー

この章は8つの手順にまとめられます。順番に実行してください。

  1. 分析概要を書く。 ビジネス上の問い、アウトカム、処置、報告期間を含む推定対象を定めます。数値を見る前に固定します。
  2. 対照系列を選ぶ。 キャンペーンが影響できなかった系列でなければなりません。キャンペーンを実施した人へ確認します。
  3. 事前期間だけに当てはめる。
  4. 反実仮想をバックテストする。 報告する予測期間で行います。好みではなく、バックテストから仕様を選びます。
  5. プラセボ介入を実行する。 実際の数値を見る前に、デザインがノイズから何を返すかを把握します。
  6. 事後期間の効果を推定する。 手順1で固定した期間を使います。
  7. 対照系列をストレステストする。 キャンペーンがそこへ届いた可能性はあるか？事前期間の関係が崩れた可能性はあるか？
  8. 反実仮想が弱ければ、因果的な数値を報告しない。 バックテスト誤差13.7%は予測であり、測定ではありません。

CausalImpactは観察データを実験へ変えるものではありません。時系列が信頼できる反実仮想を支えられるかを、構造化して問う方法です。支えられない場合、答えはより良いモデルではなく、次回のより良い実験です（Chapter 6.3）。

要点

  • 対照群がない場合、事前期間とキャンペーンが影響できなかった系列からキャンペーンなしの経路を予測し、報告する予測期間でのバックテストによって、その予測の信頼性を獲得する。
  • 2つの失敗はデータに痕跡を残さない。キャンペーンが対照系列へ届いた場合と、事前期間の関係が崩れた場合である。区間が狭いことは対照系列が役立った証拠ではなく、よりよいバックテストが証拠となる。
  • 数値を見る前に報告期間を固定する。累積曲線の頂点で止めると、全期間の答えを38%過大評価した。
